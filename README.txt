BLOOM — DAILY 100

Files:
- index.html: the app
- manifest.webmanifest + icons: Android install metadata
- sw.js: offline cache

To put it on your Android home screen:
1. Upload the contents of this folder to a static HTTPS host (for example, Netlify).
2. Open the published HTTPS site in Chrome on your Android phone.
3. Tap Chrome's ⋮ menu, then choose "Install app" or "Add to Home screen".
4. Confirm. Bloom will appear as an app icon.

Important:
- Tasks and scores are stored in this browser on this device.
- Export data regularly from the app as a backup.
- Browser storage can be cleared by Android/browser cleanup, so keep backups.
